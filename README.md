# 🏥 Clinic App
A modern Flutter application for managing medical services and improving the patient experience. The app provides authentication, doctor browsing, category filtering, and a clean medical UI.

## ✨ Features
🔐 Firebase Authentication
Email & Password Login
Register Account
Google Sign In
Apple Sign In
🩺 Medical Home Screen
Doctor Search
Categories Section
Clean UI Design
📱 Responsive UI
Built with flutter_screenutil
Works on multiple screen sizes
🧠 State Management
Bloc / Cubit Architecture
🔥 Firebase Integration
Firebase Auth
Token Handling
Persistent Login Session
